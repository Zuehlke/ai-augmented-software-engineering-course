# Lab 3 · Create your own research agent

## Context

So far, you used Copilot to generate code directly.

Now you will create a reusable workflow that specifically supports clarifying and agreeing requirements for the features you want to implement.

## Your Task

Start the lab setup with the following command:

```bash
task lab research
```

> [!IMPORTANT]
> If you work in **GitHub Codespaces**, open a **new Codespace** on branch `lab/skills`.
>
> [![Open Lab 3 in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/Zuehlke/ai-augmented-software-engineering?ref=lab%2Fskills)

After the command is finished, complete the following tasks:

- Describe the task in `/skills/research/SKILL.md`: critically review requirements, surface gaps, refine requirements, and write an improved specification.
- Invoke the skill to create the specification for:
  - `GET /delays?airline_code=AA&limit=50`

## Tips & Tricks

- The `TODO` markers in the relevant files will help you get started.
- You can find a reference solution in branch `solution/skills`.
