# Lab 5 · Spec-Driven Development (SDD)

## Context

Instead of using your own research → plan → implement workflow, make yourself familiar with a publicly available SDD framework and implement the same feature using that workflow.

Popular frameworks include:

- [GSD](https://github.com/github/spec-kit/tree/main?tab=readme-ov-file#-guided-spec-driven-development-gsd)
- [OpenSpec](https://github.com/openspec-ai/openspec)
- [Spec Kit](https://github.com/github/spec-kit)

## Your Task

Start the lab setup with the following command:

```bash
task lab/sdd
```

> [!IMPORTANT]
> If you work in **GitHub Codespaces**, open a **new Codespace** on branch `lab/sdd-with-framework`.
>
> [![Open Lab 5 in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/Zuehlke/ai-augmented-software-engineering?ref=lab%2Fsdd-with-framework)

After the command is finished, complete the following tasks:

- Learn a SDD framework of your choice.
- Implement the same endpoint again using that framework's workflow:
  - `GET /delays?airline_code=AA&limit=50`

## Solution

Files that are created depend on the framework. Choose one and follow its workflow consistently.
